Drop one image per species here, named exactly (lowercase, .jpg):

  bluegill.jpg          largemouth-bass.jpg    smallmouth-bass.jpg
  black-crappie.jpg     yellow-perch.jpg       channel-catfish.jpg
  rainbow-trout.jpg     redfish.jpg            spotted-seatrout.jpg
  striped-bass.jpg      flounder.jpg           sheepshead.jpg

The app auto-detects them: if a file is present it shows the real photo in the
reveal card and Field Guide; if it's missing it falls back to the drawn
illustration. Side-profile images work best. ~1000px wide is plenty.

You can populate this folder automatically with tools/fetch_fish_photos.py
(see that file). Mind each image's licence — keep tools/CREDITS.txt with the app.
